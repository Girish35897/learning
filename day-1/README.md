# Learning

In the day 1 we cover basics of FASTAPI 

- Create a simple student database with fastapi implementing CRUD operations

## Concepts
### CRUD - Create * Retrieve * Update * Delete
- To Create a new record : `POST` method is used (@app.post)
- To Fetch the exisiting record : `GET` method is used (@app.get)
- To update the existing record : `PUT` method is used (@app.put)
- To delete the existing record : `DELETE` method is used (@app.delete)
